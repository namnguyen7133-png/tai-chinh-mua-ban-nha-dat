💡 Mẹo tối ưu không gian (VS Code)

  • Ẩn Sidebar: Luôn nhấn Ctrl + B khi code để tận dụng chiều ngang.
  • Giao diện Terminal: Chuột phải vào tiêu đề TERMINAL chọn Move Panel Right để xem log dẽ hơn khi cửa sổ nhỏ.
  • Sticky Scroll: Vào Settings tìm "Sticky Scroll" để luôn giữ tiêu đề hàm ở đầu trang.
🔑 Lấy API Pushbullet: Web -> Settings -> Account -> Create Access Token.

* Mẹo: Nhấn F11 để bật chế độ toàn màn hình.

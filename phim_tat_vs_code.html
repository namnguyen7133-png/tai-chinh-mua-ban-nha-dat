1. Lệnh Chạy Tệp (Trong Terminal VS Code)

Ngôn ngữ Lệnh thực thi Ghi chú
Python python file_name.py Chạy script Python của bạn
HTML/JS start file_name.html Mở file bằng trình duyệt mặc định (Windows)
Node.js node file_name.js Chạy file JavaScript

2. Phím Tắt VS Code (Nâng Cao)

Phím tắt Chức năng
F5 Bắt đầu Debug / Chạy chương trình
Ctrl + ` Đóng/Mở nhanh cửa sổ Terminal
Ctrl + P Tìm và mở nhanh một tệp tin trong project
Ctrl + Shift + L Chọn tất cả các từ giống hệt từ đang bôi đen (Sửa hàng loạt)
Ctrl + / Bật/Tắt chú thích (Comment) cho dòng code

3. Phím Tắt Desktop Ảo (Windows 10/11)

Rất hữu ích khi bạn chạy nhiều shop hoặc nhiều trình duyệt cùng lúc.

Phím tắt Chức năng
Win + Ctrl + D Tạo một Desktop ảo mới
Win + Ctrl + ← / → Chuyển đổi qua lại giữa các Desktop ảo
Win + Ctrl + F4 Đóng Desktop ảo hiện tại
Win + Tab Mở Task View (Xem tất cả các cửa sổ và Desktop)

4. Lệnh Chạy Tệp Python Bằng Copy/Paste

Cách làm Lệnh / Thao tác Ghi chú
Cách 1: Kéo thả Gõ python + dấu cách, sau đó kéo file .py thả vào Terminal Nhanh nhất, không lo sai đường dẫn
Cách 2: Copy Path Gõ python " -> Dán (Ctrl+V) -> Gõ " -> Enter Dùng khi bạn đã Copy Path từ File Explorer
Cách 3: Trong VS Code Chuột phải vào File -> Chọn Copy Relative Path Lấy đường dẫn tương đối để lệnh gọn hơn

5. Mẹo xử lý nhanh với Terminal

  • Dán nhanh vào Terminal: Trong Windows Terminal hoặc VS Code, bạn có thể nhấn Chuột phải để dán (Paste) thay vì nhấn Ctrl+V.
  • Tự động hoàn thành: Gõ vài chữ cái đầu của tên file rồi nhấn phím Tab, Terminal sẽ tự điền nốt phần còn lại.
  • Chạy lại lệnh cũ: Nhấn phím ↑ (Mũi tên lên) để hiện lại các lệnh đã chạy trước đó.
